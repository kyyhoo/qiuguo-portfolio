## 项目概述

校招岗位分散于各企业官网招聘页，投递过程中难以快速识别与自身方向匹配、仍在开放、以及当日新增的岗位。

**秋果**是本人为自己秋招投递搭建的工具站，同时作为本人产品与数据分析练习项目，主要能力包括：

- 按本人履历匹配方向精选收录正式校招岗位
- 按公司首次出现去重，并按日归档，支持按日历回看
- 提供日期、城市、招聘状态、岗位类别、关键词等筛选与排序
- 「已投递」标记支持本地存储与云端同步
- 采集学习用行为事件（浏览、筛选、搜索、打开岗位、标记已投），用于指标与SQL练习

> 岗位信息来源于各公司官方招聘页；本站为个人整理与投递辅助工具，**非官方招聘平台**。完整抓取与匹配规则源码不在本仓库公开。

## 产品要点

1. **按个人方向精选收录**：不聚合全网校招信息，仅纳入与个人履历匹配的方向，降低筛选成本。 
2. **默认展示仍在招岗位**：官方招聘页通常缺少可靠截止日期；以「仍在招 / 已下线」状态帮助用户避免投递已关闭岗位。 
3. **区分岗位开放时间与收录时间**：两列独立展示，便于区分岗位实际开放节点与清单收录节点。
4. **公司按首次出现去重归档**：同一公司仅保留最早出现日期；空日亦保留，便于按日历查看增量，避免重复岗位干扰。
5. **已投递状态跨端同步**：支持本地标记与云端同步，更换设备后仍可延续投递进度。
