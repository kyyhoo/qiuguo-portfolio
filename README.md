# 秋果 · Qiuguo

个人秋招投递清单站：把分散在各公司 ATS 上的**正式校招**岗位，按简历相关方向整理成可搜、可筛、可标记「已投」的清单。

## 这是什么

秋招信息散落在 Moka / 飞书招聘等官网，投递时很难一眼看到「和自己相关、还在招、今天新开」的岗位。

**秋果**是我为自己秋招流程搭的工具站（也当作产品练习）：

- 只收录与个人履历匹配的校招方向（产品 / 运营 / 用研 / 外企管培 / 跨境电商等）
- 按公司首次出现去重，按日归档；空日也会保留，方便按日历回看
- 支持日期、城市、招聘状态（仍在招 / 已下线）、岗位类别、关键词筛选与排序
- 「已投」本地标记 + 云端同步，换设备也能接着用
- 埋了学习用行为事件（浏览 / 筛选 / 搜索 / 打开岗位 / 标记已投），方便自己练漏斗与 SQL

> 岗位原文来自各公司官方招聘页；本站是个人整理与投递辅助，**非官方招聘平台**。完整抓取与匹配规则源码不在本仓库公开。

## 产品要点

1. **默认看「仍在招」** — ATS 很少给可靠截止日期，用仍在招 / 已下线状态代替「下线日」列  
2. **岗位开放时间 ≠ 收录时间** — 两列分开，避免把「我哪天看到」和「岗位何时开放」混在一起  
3. **城市归一** — 合并「广东省-深圳 / 深圳」等写法；境外统一进「海外」地点桶  
4. **类别服务投递决策** — 产品经理、用户研究、各类运营等；跨境相关进业务类别，不单独占一个「海外」类别 chip
